## Root cause
Worktree inherited the integration merge (76bf0c5) of hydra-zpyj, which re-introduced the OLD pre-fix duplicate-PR handling from 3d6b9ef alongside the new resolver: `isPRAlreadyExists` declared twice (vet: "isPRAlreadyExists redeclared in this block"), and `publishBranchViaPROnce` returned `"already-exists", nil` without merging, while `publishBranchViaPRCreate`/`PublishViaPR` fell through to merge even when the existing PR was unresolvable (CLOSED PR or lookup failure).
