## Refactor: Streamline Hydra Core

This PR extracts subsystems from the Overseer god object and removes dead code.

### What's Changed

**Overseer Decomposition**
- Extract `SpawnRateLimiter` — spawn rate limiting + backoff (-5 methods)
- Extract `RetryManager` — bead retry + validation retry tracking (-7 methods)
- Add `IntelligenceHub` — TLDR/GPTCache/Hindsight client encapsulation (ready for integration)

**Dead Code Removal**
- Remove `config/hindsight.go` — unused config structs
- Remove `config/intelligence.go` — unused config structs
- Remove `dashboard/expertise.go` — unused dashboard types
- Remove `agents/consensus-facilitator.go` — entire file unreachable
- Remove `internal/core/activity_monitor.go` — duplicate of worker monitor
- Remove `internal/agents/connector.go` AgentRegistry — no callers

**New Packages**
- `pkg/cli/runner.go` — unified CLI command execution

### Design Decisions
- Each extracted type is self-contained with its own mutex
- Overseer delegates to extracted types, no behavior change
- IntelligenceHub created but not yet integrated (high coupling with settledStateSvc)
